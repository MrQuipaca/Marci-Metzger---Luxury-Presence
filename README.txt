# Marci Metzger Homes

A responsive real estate website developed as part of the **Junior Website Builder assignment at Luxury Presence**.

The website showcases Marci Metzger's real estate services in Pahrump, Nevada, focusing on clean design, intuitive navigation, and user experience.

## Features

- Responsive design for desktop, tablet, and mobile.
- Interactive navigation with active section highlighting.
- Property search interface with multiple filters.
- Dynamic image gallery using Bootstrap Carousel.
- Real estate services and partner sections.
- Contact form interface and Google Maps integration.
- Cookie acceptance banner using local storage.
- SEO metadata and favicon support.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.3.3
- Bootstrap Icons
- Google Fonts
- Google Maps

## Getting Started

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Launch `index.html` in your browser or use the Live Server extension.

No build process or package installation is required.

## Notes

The property search and contact form currently demonstrate front-end interactions and require backend integration for full functionality.
