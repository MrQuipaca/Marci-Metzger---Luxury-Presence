Marci Metzger Homes — front-end test replica
===========================================

Files:
- index.html: page structure and demo content
- style.css: responsive styling
- script.js: mobile navigation, demo listing filters, demo contact form

Run:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Internet access is needed for Google Fonts and remote Unsplash images.

Notes:
- This is a test-only visual recreation inspired by the public website. It is not the original source code and is not an exact pixel-perfect copy.
- Sample properties/prices are illustrative, not real or live MLS listings.
- Search filters operate on the three sample cards only.
- Contact form does not submit data.
- Images are loaded from Unsplash URLs and may be changed if a URL is unavailable.
